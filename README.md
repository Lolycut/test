# Инструкция по размещению сайта «ИЗЮМ» на hoster.by (тариф «Лайт») и подключению K-9 Mail

## 1. Характеристики тарифа «Лайт» (hoster.by) и оптимизация сайта
Тариф виртуального Unix-хостинга **«Лайт»** на `hoster.by` включает:
- **Дисковое пространство:** 3 ГБ на быстрых SSD/NVMe-дисках (весь наш сайт со всеми 12 моделями в формате `.webp` весит **менее 1 МБ**, то есть занимает менее 0,03% диска!).
- **Сайтов на аккаунте:** до 5 сайтов.
- **Почтовые ящики на домене:** неограниченно (`∞`), расположены физически на серверах в Республике Беларусь.
- **SSL-сертификат:** бесплатный автопродляемый **Let's Encrypt** (включён в тариф).
- **Панель управления:** cPanel + поддержка PHP 7.4 / 8.1 / 8.2 / 8.3 и `.htaccess`.

## 2. Выгрузка сайта на хостинг hoster.by
1. Войдите в панель **cPanel** вашего хостинга на `hoster.by` (ссылка и логин находятся в письме об открытии услуги «Виртуальный хостинг: Лайт»).
2. Откройте **«Диспетчер файлов» (File Manager)** → перейдите в папку `public_html` (или папку вашего домена `izum-home.by`).
3. Загрузите архив `izyum-home-hoster.zip` и нажмите **«Извлечь» (Extract)** в корень `public_html`.
4. В разделе **«SSL/TLS Status»** в cPanel убедитесь, что для домена выпущен бесплатный сертификат **AutoSSL (Let's Encrypt)** — файл `.htaccess` автоматически перенаправит всех посетителей на защищённый `https://`.

## 3. Создание доменной почты в cPanel (внутри Беларуси по Закону № 99-З)
1. В панели **cPanel** откройте раздел **«Почтовые аккаунты» (Email Accounts)** → нажмите **«Создать» (Create)**.
2. Создайте два ящика на вашем домене:
   - `info@izum-home.by` (или `orders@izum-home.by`) — основной ящик менеджера для приёма заявок в **K-9 Mail**.
   - `noreply@izum-home.by` — технический ящик сайта, от имени которого скрипт `api/lead.php` отправляет заявки.
3. Если вы назвали ящик иначе (например, `orders@izum-home.by`), укажите его в файле `api/config.php` в строке `'mail_to' => 'orders@izum-home.by'`.
4. В разделе **«Email Deliverability»** в cPanel проверьте, что для домена активны записи **SPF** и **DKIM** (на `hoster.by` они включаются автоматически).

## 4. Настройка приложения K-9 Mail на Android для мгновенного приёма заявок
В письме от `hoster.by` при открытии хостинга указан ваш почтовый сервер вида `mailbeXX.hoster.by` (например, `mailbe05.hoster.by`), либо можно использовать `mail.izum-home.by`.

1. Откройте **K-9 Mail** на телефоне → **Добавить аккаунт**:
   - **Адрес эл. почты:** `info@izum-home.by`
   - **Пароль:** пароль от этого почтового ящика, заданный в cPanel.
2. Нажмите **«Ручная настройка»** → выберите тип аккаунта **IMAP**:
   - **Сервер входящей почты (IMAP):** `mailbeXX.hoster.by` (или `mail.izum-home.by`)
   - **Безопасность:** `SSL/TLS`
   - **Порт:** `993`
   - **Имя пользователя:** `info@izum-home.by` (полный адрес!)
   - **Метод аутентификации:** `Обычный пароль`
3. Нажмите «Далее» → **Сервер исходящей почты (SMTP)**:
   - **Сервер SMTP:** `mailbeXX.hoster.by` (или `mail.izum-home.by`)
   - **Безопасность:** `SSL/TLS`
   - **Порт:** `465`
   - **Требовать вход в систему:** включено (`info@izum-home.by` и ваш пароль).
4. **Мгновенные Push-уведомления о новых заявках:**
   - В настройках аккаунта в K-9 Mail → **«Получение почты»** установите:
     - **Частота проверки папок:** `Каждые 15 минут` (для подстраховки)
     - **Папки для Push (IMAP IDLE):** `Папка 1-го класса` (Входящие / Inbox) — благодаря этому новые заявки с сайта будут приходить на телефон со звуковым уведомлением **за 1–2 секунды** после нажатия кнопки клиентом на сайте!
   - В каждом письме есть большая кнопка **«Позвонить: +375 (XX) XXX-XX-XX»** — при нажатии на неё в K-9 Mail сразу открывается набор номера клиента.
